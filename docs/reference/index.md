# Interface reference

The reference section records the pipeline's automation surfaces: command-line
entry points, YAML schemas, environment variables, generated paths, exit status,
and JSON objects written to standard output.

Use it to write drivers and audits. Use the learning path and how-to guides when
you need an end-to-end procedure.

- [Command-line interface](cli.md) lists project-owned entry points and options.
- [Configuration](configuration.md) describes the tracked generation, training,
  cluster, and personal-overlay YAML surfaces.
- [Environment variables](environment.md) separates operator input, generated
  job state, and documentation-only conventions.
- [JSON output contracts](json-output.md) defines machine-readable result shapes
  and exit semantics.
